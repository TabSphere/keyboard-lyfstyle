# Lyfstyle v1.1 plan

Goal: move from "MVP" to a complete fonts-keyboard product that beats free, ad-funded competitors
(for example Style King: free with ads, shares user data, ~1k downloads) on depth, design and privacy.

Principles that stay: no ads, no tracking, no account, works offline, one-time Pro.

## 1. Redesign

- New visual direction, chosen from the three boards (A Pop, B After Hours, C Sugar).
- New logo colour (the "lyf" mark stays; colours follow the chosen palette).
- Four tabs: **Write**, **Styles**, **Tools**, **Keyboard** (Settings moves under a top-right icon).
- Every screen redone: Write, Styles gallery, Tools hub, Keyboard setup + theme picker, Pro, Settings.

## 2. Text styles: 24 → 100+

| Group | Examples | Count |
|---|---|---|
| Unicode fonts (existing) | Script, Fraktur, Outline, Sans, Mono, Bubble, Squares… | 24 |
| More Unicode fonts | Tiny caps, wide, inverted, mirrored, cursive variants, regional letters | ~16 |
| Combining effects | Glitch, slash, wave, dots, cross-out, double underline | ~12 |
| Emoji frames | ✨ text ✨, 🌸 text 🌸, ★彡 text 彡★, 『 text 』, ʚ text ɞ | ~30 |
| Between-letter styles | h♡e♡a♡r♡t, s p a c e d, b·u·l·l·e·t | ~10 |
| Kaomoji add-ons | text (｡♡‿♡｡), ʕ•ᴥ•ʔ text | ~10 |

Free: about 40, picked so free users never feel stuck. Pro: everything.

## 3. Presets (new)

Tap-to-use bio, caption and username templates in categories: Aesthetic, Love, Savage, Birthday, Gym, Travel, Gaming.
Shipped in the app (no network). Around 150 at launch, more in updates.

## 4. Keyboard

- Themes 4 → 24 in the chosen direction's style, plus **Custom theme** (colours, or your own photo; Pro).
- Style bar above the keys: recent styles + emoji frames one tap away.
- New **Symbols & kaomoji panel**: stars, hearts, arrows, dividers, faces.
- Keeps: no Full Access needed for core typing, Normal mode in password fields, grapheme-safe delete.

## 5. Tools tab (new)

1. Text repeater
2. Emoji to text (big emoji letters, e.g. a word drawn with 💖)
3. Quote / story card maker (styled text on a background, saved as an image)
4. Username generator (from a name + style)
5. Symbols & kaomoji library

## 6. Pro

- Product `com.tabsphere.keyboardlyfstyle.pro`, non-consumable, £7.99 test price, store-localised.
- Must be created in Play Console and App Store Connect (current "SKU not found" error).
- Unlocks: all styles, all themes, custom theme, all preset packs, card maker backgrounds.

## Build order

1. Pick direction → design tokens, logo colour, app icon.
2. Style catalogue 100+ (shared `styles.json`, golden tests in TS, Swift, Kotlin).
3. Write + Styles + Presets screens.
4. Keyboard themes + style bar + symbols panel (iOS + Android).
5. Tools tab.
6. Pro product in both stores, then new internal test builds.
